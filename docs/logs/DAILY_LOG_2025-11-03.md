## 操作速查（Windows PowerShell）

- 開 GUI（直接執行）
```powershell
python tools/fill_pdf_gui.py
```

- 開 GUI（已安裝後的 entry script）
```powershell
handfont-fill-pdf-gui
```

- CLI 填表（簡單版）
```powershell
python tools/fill_pdf_simple.py --template .\samples\template.pdf --output .\out.pdf --values .\samples\values_sample.json --clear-annots --random
```

- 開啟 src 佈局實驗（暫時環境變數）
```powershell
$env:PYTHONPATH = "src"; python tools/fill_pdf_gui.py
```

- 開發模式安裝（建議）
```powershell
pip install -e .
```

## 注意事項 / 風險

- 資源打包：搬移到 src 後，記得在 `pyproject.toml`/`MANIFEST.in` 保持 `fonts/`、`configs/`、`version.json` 被包含。
- 字型路徑：GUI 欄位字型覆寫會尋找 `fonts/`；搬移後請檢查 `BASE_DIR` 與實際位置一致。
- 註解鍵：PDF 需使用 FreeText 註解的 `content` 作為鍵；缺鍵會列入警示。
- 隨機化：導出可關閉/覆寫；若要完全重現結果，請關閉隨機化並固定所有覆寫值。

## 快速暖機（10 分鐘）

1. 打開專案根，在 VS Code 啟動終端。
2. 執行 GUI：`python tools/fill_pdf_gui.py`。
3. 先選 PDF → 讀取欄位（確認欄位鍵）→ 載入 `samples/values_sample.json`。
4. 用「進階設定（全域）」微調線寬/模糊/抖動，點「預覽」。
5. 挑 1~2 個欄位開「設定」→「進階…」做 per-field 微調，確認優先序。
6. 輸出 PDF，檢查視覺效果。
